# Production-readiness gates

1. Obtain formal PHISC permission and identify the canonical publisher.
2. Verify every field, conditionality rule, code list and cardinality against the licensed PHISC source.
3. Replace example terminology with governed complete CodeSystems or external canonical references.
4. Add discipline-specific profiles and examples for dental, pharmacy, pathology, radiology and optometry.
5. Define amendment, replacement, credit-note, duplicate and idempotency semantics.
6. Complete security, POPIA, consent, audit, non-repudiation and retention specifications.
7. Run connectathons with providers, switches and administrators.
8. Resolve all SUSHI, publisher and validator errors before release.
9. Establish change control, package publication and semantic versioning.
